# Godot API Check Skill Specification

## Goal

Create a Codex skill that exports and queries the complete Godot Engine GDExtension API surface.

## Artifacts

- `extension_api_check/extension_api.json`: Godot 4.6.2 stable API dump generated with `--dump-extension-api`.
- `extension_api_check/godot-api-check/SKILL.md`: Skill instructions and trigger description.
- `extension_api_check/godot-api-check/scripts/query_godot_api.py`: Reusable export and query utility.
- `extension_api_check/godot-api-check/agents/openai.yaml`: UI metadata generated by the skill initializer.
- `.codex/skills/godot-api-check`: Project-local installed copy so Codex can discover the skill in this workspace.
- `.codex/skills/godot-api-query-required`: Project-local mandatory workflow skill requiring Godot API lookup before use.
- `AGENTS.md`: Repository rules for file naming, Godot API lookup requirements, project symbol verification, and Chinese code comments.
