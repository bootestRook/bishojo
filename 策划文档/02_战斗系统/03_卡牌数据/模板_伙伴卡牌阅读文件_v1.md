# 伙伴卡牌阅读文件模板

本文档是单张伙伴卡牌的 Markdown 阅读模板。每张卡牌必须复制本模板生成独立文件，不得继续把多张卡牌写入同一个总表。

## 文件规则

- 当前角色 1 卡组的单卡阅读文件放在 `策划文档/02_战斗系统/03_卡牌数据/01_角色1卡组/`。
- 单卡阅读文件命名使用 `内容_[卡牌名]卡牌_v1.md`，例如 `内容_狗头人卡牌_v1.md`。
- 单卡开发数据放在 `data/cards/partners/`。
- 单卡开发数据命名使用 `[card_id].v1.json`，例如 `kobold.v1.json`。
- 新增字段时，必须同步更新：
  - 本 Markdown 模板；
  - `data/cards/templates/partner_card.template.v1.json`；
  - 所有已录入单卡 Markdown 文件；
  - 所有已录入单卡 JSON 文件。
- 未提供截图或无法确认的字段，Markdown 写 `待确认`，JSON 写 `null`，不得按数值规律外推。
- 只有卡牌自身主动/被动效果直接对敌人造成伤害时，才打上 `伤害卡牌` 标签；仅引用 `伤害伙伴` 或给其他卡牌 `+X 点伤害` 不算伤害卡牌。
- 被动描述若写明“触发某事件时，获得/增加某数值”，则默认每次事件触发都叠加一次。
- 持续时间若没有特殊说明，则默认持续到本场战斗结束。
