# 狗头人卡牌

## 基础信息

| 字段 | 内容 |
|---|---|
| 卡牌ID | `kobold` |
| 卡牌名字 | 狗头人 |
| 卡牌类型 | 伙伴 |
| 对应开发数据 | `data/cards/partners/kobold.v1.json` |
| 卡牌体型大小 | 小型 |
| 技能初始冷却 | 7 秒 |
| 标签 | 伤害卡牌 |
| 标签依据 | 冷却触发效果和被动触发效果均包含“伤害” |

| 品质 | 开发键 | 卖出价钱 | 卡面顶部数值 | 冷却触发具体效果描述 | 被动触发具体效果描述 | 待确认项 |

| 绿色 | `green` | 1 | 20 | 对敌人造成 20 点伤害 | 其他伙伴触发暴击时：此伙伴 +5 点伤害 | 无 |

| 紫色 | `purple` | 4 | 40 | 对敌人造成 40 点伤害 | 其他伙伴触发暴击时：此伙伴 +15 点伤害 | 无 |
| 金色 | `yellow` | 8 | 50 | 对敌人造成 50 点伤害 | 其他伙伴触发暴击时：此伙伴 +20 点伤害 | 无 |

## 开发实现备注

| 项目 | 内容 |
|---|---|
| 冷却触发结构 | `cooldown_ready` 时对单个敌人造成直接伤害，数值按品质读取 |
| 被动触发结构 | `other_ally_crit` 时给自身增加固定伤害，数值按品质读取 |
| 叠加规则 | 每次其他伙伴触发暴击时叠加一次 |
| 持续规则 | 描述未写特殊持续时间，默认持续到本场战斗结束 |
| 实现待定规则 | 主动伤害的伤害类型、是否参与暴击、是否触发吸血仍需按战斗协议或实测确认 |
